# Athena brand assets

The five supplied 2,000 × 2,000 PNG masters are preserved unchanged under `public/brand/originals/`:

| Asset | Intended use |
| --- | --- |
| `athena-horizontal-lockup.png` | Wide marketing and presentation layouts |
| `athena-figure.png` | Full-height Athena illustration |
| `athena-stacked-lockup.png` | Square or portrait title layouts |
| `athena-wordmark-dark.png` | Wordmark on the Athena charcoal background |
| `athena-wordmark-light.png` | Wordmark on light backgrounds |

Web derivatives preserve the supplied pixels and do not redraw the mark:

- `public/brand/athena-app-icon.png` is the square helmet/portrait crop used by the application shell, metadata, Apple touch icon, and web app manifest.
- `public/brand/athena-wordmark.png` is the compact charcoal wordmark used in the expanded navigation.

The official charcoal sampled from the supplied artwork is `#181f21`. The original PNGs have opaque backgrounds; use the preserved master appropriate for the destination background rather than assuming transparency.
